# Complete-Tableau-Attrition-Analysis
This Project uses Tableau to answer many important business questions and summarizes the final results with a Dashboard.
KPI's Requirements
1. Employee Count
2. Attrition Count
3. Attrition Rate
4. Active Employee
5. Average Age

Dashboard Requirements
1. Attrition by Gender
2. Number of employee by age group
3. Job satisfaction Rating
4. Education field wise Attrition
5. Attrition rate by gender for different age group.
